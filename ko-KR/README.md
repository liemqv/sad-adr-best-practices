# 솔루션 아키텍처 문서 (SAD) - 모범 사례

> 현대적인 표준과 C4 모델을 사용하여 솔루션 아키텍처 문서를 작성하기 위한 템플릿 및 모범 사례 가이드.

## 📋 개요

이 디렉토리는 2026년 업계 모범 사례를 따르는 솔루션 아키텍처 문서(SAD)를 위한 현대적이고 포괄적인 템플릿을 제공합니다. 템플릿에는 다음이 포함됩니다:

- **C4 모델**을 통한 아키텍처 시각화
- **Mermaid 다이어그램**을 통한 GitHub 네이티브 다이어그램 렌더링
- **4+1 아키텍처 뷰 모델** 원칙
- 필수 구성 요소로서의 **논리 뷰** 및 **배포 뷰**
- 데이터 모델링을 위한 **엔티티 관계도(ERD)**

## 📁 디렉토리 내용

### 템플릿
- **`SAD-Template.md`**: 모든 섹션, 다이어그램 및 예제가 포함된 완전한 SAD 템플릿
- **`ADR-Template.md`**: 아키텍처 결정 기록(ADR)을 위한 경량 템플릿
- **`README.md`**: 이 파일 - 디렉토리 개요 및 사용 가이드

### 예제
- **`Example/SAD-Example.md`**: 실제 사례 - 공유 차량 플랫폼(Uber와 유사한 시스템)을 위한 완전한 SAD
- **`Example/ADR-001-Example.md`**: ADR 예제 - 마이크로서비스 아키텍처 결정

## 🚀 빠른 시작

1. 이 저장소를 **복제하거나 다운로드**
2. **`Example/SAD-Example.md`**를 검토하여 완전한 실제 사례 확인
3. **`SAD-Template.md`**를 프로젝트에 복사
4. 특정 아키텍처 세부 정보로 템플릿 **사용자 정의**
5. 예제 다이어그램을 실제 시스템 아키텍처로 **교체**
6. 프로젝트별 정보로 섹션 **업데이트**
