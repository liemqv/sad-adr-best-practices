# Dokumen Arsitektur Solusi (SAD) - Praktik Terbaik

> Template dan panduan praktik terbaik untuk membuat Dokumen Arsitektur Solusi menggunakan standar modern dan model C4.

## 📋 Ikhtisar

Direktori ini menyediakan template modern dan komprehensif untuk Dokumen Arsitektur Solusi (SAD) yang mengikuti praktik terbaik industri untuk tahun 2026. Template mencakup:

- **Model C4** untuk visualisasi arsitektur
- **Diagram Mermaid** untuk rendering diagram native GitHub
- **Prinsip model tampilan arsitektur 4+1**
- **Tampilan Logis** dan **Tampilan Deployment** sebagai komponen yang diperlukan
- **Diagram Relasi Entitas (ERD)** untuk pemodelan data

## 📁 Isi Direktori

### Template
- **`SAD-Template.md`**: Template SAD lengkap dengan semua bagian, diagram, dan contoh
- **`ADR-Template.md`**: Template ringan untuk Catatan Keputusan Arsitektur (ADR)
- **`README.md`**: File ini - ikhtisar direktori dan panduan penggunaan

### Contoh
- **`Example/SAD-Example.md`**: Contoh dunia nyata - SAD lengkap untuk platform berbagi tumpangan (sistem serupa Uber)
- **`Example/ADR-001-Example.md`**: Contoh ADR - Keputusan arsitektur mikrolayanan

## 🚀 Mulai Cepat

1. **Kloning atau unduh** repositori ini
2. **Tinjau** `Example/SAD-Example.md` untuk melihat contoh dunia nyata yang lengkap
3. **Salin** `SAD-Template.md` ke proyek Anda
4. **Sesuaikan** template dengan detail arsitektur spesifik Anda
5. **Ganti** diagram contoh dengan arsitektur sistem aktual Anda
6. **Perbarui** bagian dengan informasi spesifik proyek
